# 牛马笔记 · Notema

> 灵感跑不掉，牛马不焦虑 —— 在 AI 时代，你只管复制粘贴。

牛马笔记是一个**完全免费、纯本地保存**的单文件笔记工作台。复制网页、AI 回答、聊天记录里的任意内容，`Ctrl+V` 粘贴即成卡片、自动归档，记录、整理、回顾、沉淀全在同一个页面闭环完成。

- **免费**：无付费墙、无广告、无账号体系，永不过期
- **纯本地**：数据只存在你自己的浏览器里，不上传、不联网
- **单文件**：一个 HTML 文件开箱即用，零依赖、零安装

## 为什么做它

现在的 AI 时代，几乎每个职场牛马都在跟 AI 打交道：问问题、找工作、想方案、写材料。AI 张口就来，总能给出不少启发和灵感——但回答太快、信息太多，根本来不及第一时间归纳整理。上一秒还觉得惊艳的思路，下一秒就淹死在聊天记录里。

所以牛马笔记只做一件事：把「收集」变得毫无门槛。**复制、粘贴，自动变成卡片、自动归档**。先收下，整理的事交给以后。

| 名人名言 | 空分类随机轮播记录 / 笔记 / 实践 / 创新主题名言（上下渐变切换） |
| 交互音效 | 点击、保存、删除、拖拽、置顶等十余种操作音效 |

## 快速开始

**线上使用**：打开 [https://china-seachange.github.io/notema/doing/index.html](https://china-seachange.github.io/notema/doing/index.html)

**本地使用**：下载文件，双击用浏览器打开即可（单文件自包含，无需安装任何依赖）。

看到好内容 → `Ctrl+C` 复制 → 回到页面任意位置 `Ctrl+V`，卡片即刻生成。

首次打开会有引导说明，勾选「下次不再提示」即可跳过。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl / ⌘ + V` | 任意位置粘贴成卡片，自动归入当前分类 |
| `Ctrl / ⌘ + Z` | 撤销（新增 / 删除 / 置顶 / 调整分类等所有操作） |
| `Ctrl / ⌘ + Y` | 恢复 |
| `Ctrl / ⌘ + Enter` | 编辑弹窗内快速保存 |
| `Delete` | 删除选中的单张 / 多张卡片（带确认） |
| `双击卡片` | 进入编辑模式 |
| `单击标题两次` | 标题进入光标编辑，回车确认 |
| `长按卡片（约 0.45 秒）` | 抓取拖拽：互换卡片位置 / 拖入左侧分类 |
| `Ctrl + 单击卡片` | 多选 |
| `单击图片` | 放大预览；`← / →` 切换上一张 / 下一张，滚轮缩放 |

## 数据与隐私

- 所有笔记与图片均保存在**本地浏览器**（localStorage + IndexedDB），不上传任何服务器
- 可一键导出 JSON 备份（含图片数据），随时迁移到其他浏览器 / 电脑
- 删除图片后仍可用 `Ctrl+Z` 完整恢复；真正不再引用的孤儿图片数据会被自动清理，不占多余空间

## 分类说明

- 默认预设三个分类：**工作**、**生活**、**其他**（均可改名、改图标、改颜色）
- 「未分类」固定显示在分类列表**末尾**，收纳粘贴时不属于任何分类的内容
- 双击分类名打开弹窗编辑：图标任选、预设颜色 + 原生拾色器
- 分类可长按拖拽调整顺序；置顶的分类有图钉标记

## 技术实现

- 原生 HTML / CSS / JavaScript，单文件自包含，无任何外部依赖（离线可用）
- Markdown 渲染：自实现轻量解析（标题、加粗、列表、表格、代码、链接、任务项）
- 图片存储：IndexedDB（`niuma-note-imgs`），localStorage 仅存元数据，旧数据自动迁移
- 无限撤销：快照式历史栈（最多 2000 步），覆盖卡片、分类、便签全部操作
- Word 导出：Word 兼容 HTML（`.doc`），图片以 Data URL 内嵌
- 批量 ZIP：自实现 STORE 压缩包（CRC32 + 中央目录，UTF-8 文件名）
